# FlexTrack Workout Tracker 💪

**FlexTrack** is a workout tracker app designed to help fitness enthusiasts create, organize, and track their workout routines efficiently. This project demonstrates my ability to design and develop responsive web applications, manage complex data structures, and build intuitive user interfaces.

![Description of the screenshot](images/Screenshots/Screenshot2024-12-19at6.46.51PM.png)

---

## Key Features 🏋️‍♂️

### 🏋️‍♀️ Workout Routine Management

- Create personalized workout routines.
- Assign exercises with customizable sets, reps, and weights.
- Track progress for each exercise to monitor fitness goals.

### 📱 Responsive Design

- Fully optimized for mobile and desktop devices.
- Clean and transparent UI with white-outlined designs for a sleek, modern look.

### 🔄 Dynamic Exercise Tracking

- Easily update routines and exercises.
- Interactive components for editing and adjusting workout details.

### 🗂️ Structured Data

- Relational database with entities for users, routines, exercises, and routineExercises.
- Implements a 1-to-many relationship between routines and exercises.

---

## Technologies Used 🛠️

### Frontend

- **React.js**: Built the user interface and handled state management.
- **CSS/Flexbox**: Designed a responsive and visually appealing layout.

### Backend

- **JSON Server**: Simulated persistent storage for development.

### Tools & Frameworks

- **Jest**: Unit testing for reliable functionality.
- **Cypress**: End-to-end testing to ensure a seamless user experience.
